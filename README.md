# Kookie Stacks

Kookie Stacks is an innovative mobile application for a school-based confectionery business that combines traditional commerce with blockchain technology. This full-stack application enables students to browse, order, and pay for confectionery items using both traditional currency (Naira) and cryptocurrency (Stacks).

## Key Features

- **Dual Payment System**: Seamlessly accept payments in both Naira (via Moniepoint) and Stacks cryptocurrency (via Xverse wallet)
- **Interactive Product Catalog**: Browse confectionery items with detailed descriptions and images
- **Special Combo Offers**: Discounted combinations of popular items
- **Loyalty System**: Gamified "Stack Coins" reward system where purchasing premium combos earns digital tokens
- **Reward Redemption**: Exchange earned coins for free items, discounts, or conversion to Stacks
- **Order Tracking**: Real-time status updates for pending orders
- **User Profiles**: Save preferences, payment information, and view order history

## Technology Stack

- **Frontend**: React Native for cross-platform mobile experience
- **Backend**: Node.js with Express
- **Database**: MongoDB
- **Authentication**: JWT-based secure authentication
- **Payment Processing**: 
  - Moniepoint API for Naira transactions
  - Stacks.js integration for cryptocurrency payments
- **State Management**: Redux for predictable state handling
- **UI Components**: Custom components with React Native Paper

## Target Audience

School students and staff looking for a convenient, modern way to order confectionery items with the added benefits of cryptocurrency education and rewards.
